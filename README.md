# Лабораторная работа №5. Элементы сетевого программирования

## Индивидуальный вариант
- **Вариант:** 4 — Чат с временным хранением сообщений
- **STUDENT_ID:** 016 (`BASE_PORT = 20016`, `SEED = 2552`)
- **Назначение приложения:** Клиент-серверный чат на базе Windows Sockets (Winsock2) с временным хранением сообщений для отключившихся пользователей (лимит очереди — 20 непрочитанных сообщений на получателя), сохранением порядка FIFO, подтверждением доставки (`ACK`) и отклонением при переполнении (`QUEUE_FULL`).
- **Транспортный протокол:** TCP.

## Требования к окружению
- ОС: Windows 11
- Компилятор: `g++` (GCC 16.2.0, стандарт C++17) + библиотека `ws2_32`
- Python 3.14 + `matplotlib` (для запуска автотестов, серии экспериментов и построения графиков)

## Сборка
```powershell
g++ -std=c++17 -Wall -Wextra src/server/main.cpp src/common/net.cpp src/common/protocol.cpp -o server.exe -lws2_32
g++ -std=c++17 -Wall -Wextra src/client/main.cpp src/common/net.cpp src/common/protocol.cpp -o client.exe -lws2_32
